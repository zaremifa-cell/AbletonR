# Working Rules Template

## Startup Requirements

Before work begins, read the project governance files and determine:

- task scope
- relevant standards
- likely affected files
- files and sections that must not be changed
- required verification

## Scope Rules

- Change only what was requested.
- Do not touch unrelated sections.
- Do not refactor unrelated code.
- Do not update dependencies unless required.

## Session Rules

- Keep changes narrow and auditable.
- Stop and ask for clarification when ambiguous.
- Create a session log for meaningful work.
- Update the session index.

## End-Of-Session Requirements

- Record files changed.
- Record exact work performed.
- Record unresolved issues.
- Record verification status.
- Record reusable lessons when evidence supports them.
