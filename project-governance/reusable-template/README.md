# Reusable Project Governance Template

Copy this folder into another project and replace placeholder text.

Recommended structure:

- `PROJECT_WORKFLOW.md`
- `project-governance/README.md`
- `project-governance/project-brief.md`
- `project-governance/working-rules.md`
- `project-governance/design-standards.md`
- `project-governance/technical-standards.md`
- `project-governance/quality-control.md`
- `project-governance/session-index.md`
- `project-governance/sessions/`
- `project-governance/review/`

Use these templates to define project-specific workflow, standards, session history, and review-cycle practices.
