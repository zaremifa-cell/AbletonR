## Implementation Notes

- Added a mobile-only Ableton-logo menu with vertical links for `Live`, `Push`, `Move`, `Note`, `Packs`, `Shop`, and `Learn`.
- Added hash scrolling so mobile menu links to homepage sections such as `Note` and `Learn` can work from other routes.
- Reworked `Footer` so the newsletter signup is reusable and the full footer can be rendered inside Shop with a custom newsletter kicker.
- Removed the Shop `Latest` section and replaced it with the full homepage lower section, including newsletter, Ableton footer columns, social links, `Made in Berlin`, logo, legal links, and copyright.
- Adjusted Shop product cards so each product is framed as a full rectangle with even 1px border treatment.
- Removed a blocking wheel handler that broke product rail scrolling; retained CSS overscroll containment to reduce browser-level horizontal navigation.
- Added a thin Shop product progress rail below the product cards instead of dots. The moving thumb uses the existing Ableton orange accent and uses `left` plus width math so it reaches the end of the track.
- Split the Shop hero description into explicit line spans so the second line can be measured and aligned precisely with `View cart`.
- Measured the Shop hero vertical alignment in the rendered DOM. Final measurement: distance from the lower hero line to `Buying flow` is 35px, and distance from the lower hero line to `View cart` is 35px.

## User Feedback Captured

- The user dislikes classic three-dot carousel indicators for this Shop product rail.
- The user accepted the thin progress rail direction for indicating horizontal scroll.
- The progress rail thumb should use the same orange accent as the top promo marker, not the neutral ink color.
- Product cards in Shop should read as complete rectangular containers; inner divider lines must not become visually thicker than outer edges.
- Horizontal product scrolling must remain usable and must not trigger browser back/forward-style navigation.
- When the user asks to copy the bottom homepage section into Shop, that means the full lower section including newsletter, Ableton footer, `Made in Berlin`, logo, copyright, and legal links, not only the newsletter block.
- Header alignment changes must preserve the vertical relationship of `Shop` and its description. Do not split them into separate horizontal columns unless explicitly requested.
- For precise alignment complaints, use code-level geometry and user screenshots by default. Measure rendered DOM geometry only when the user explicitly asks for browser verification.
