## Exact Changes Made

- Created `codex/next-app-router-migration`.
- Installed Next.js 16.2.9, React 19.2.7, React DOM 19.2.7, React 19 type packages, and `eslint-config-next`.
- Added `next.config.ts`.
- Replaced the Vite runtime scripts with Next runtime scripts. The initial migration temporarily retained legacy comparison commands; those were removed in the cleanup pass.
- Added `src/app/layout.tsx` and App Router pages for Home, Live, Live Experiment, Push, Move, Note, Rent-to-Own, Packs, Pack detail, Shop, Cart, Checkout, Account, Product detail, and not-found.
- Moved legacy React route components from `src/pages` to `src/views` so Next does not treat them as Pages Router files.
- Added a client `SiteShell` that wraps the app in `CartProvider`, `PackPreviewProvider`, and the shared `Nav`.
- Added a small Next navigation adapter in `src/lib/navigation.tsx` to reduce migration risk while components are moved off React Router semantics.
- Refactored Packs to receive `packSlug` from App Router and use context for active pack preview state.
- Refactored Shop to receive route props instead of reading React Router location/params.
- Added `generateStaticParams` and `generateMetadata` for Pack detail routes.
- Added `generateStaticParams` and `generateMetadata` for Shop product routes.
- Guarded account localStorage helpers for SSR/prerender.
- Updated unit tests to mock `next/navigation` and render Shop by route props.
- Updated Playwright and Lighthouse config to target the Next dev server on port `3000`.
- Updated ESLint ignores for `.next`.
