## Durable User Criteria

- Do not run browser or screenshot visual checks unless explicitly asked. The user will provide screenshots when visual correction is needed.

- Use the existing design system before inventing new shapes, sizes, colors, or typography.

## Things To Watch Next

- Before adding UI, inspect existing matching components and copy their dimensions first.
- For buttons, check `.btn`, `.nav-end .btn`, `.pack-buy-button`, `.sub-field`, and page-specific controls before inventing sizes.
- For visual experiments, keep the reversible block obvious and small.
- When the user says a change is exploratory, do not over-integrate it into broad design system rules until accepted.
- Always distinguish technical build success from visual approval. Build passing is not visual approval.
