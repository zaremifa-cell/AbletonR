## Request

Build a high-end front-end Shop flow for the Ableton redesign portfolio project. The Shop should demonstrate e-commerce UI/UX, product hierarchy, interaction design, cart state, checkout, and demo account flow without backend, real authentication, or real payment processing.

## Interpretation

The implementation should feel like a professional front-end prototype, not a backend application. The visual system should stay within the existing Ableton redesign language: minimal, grey/industrial, restrained, premium, and clean. Braun and Apple are structural references only, not visual targets. No browser checks should be run unless the user asks; visual verification should come from user screenshots when needed.
